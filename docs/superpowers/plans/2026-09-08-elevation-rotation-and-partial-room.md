# Единичный сбой фасада: поворот и сохранение остальных видов

Сообщение пользователя: Revit 2024, помещение 3-19.1.1 (6289801), ошибка «Не удалось направить фасад к стене» повторяется только здесь. Дополнение: пропускать ошибочные виды, сохраняя остальные развёртки помещения.

Подтверждено кодом: проверка после RotateElement вызывает исключение, которое откатывает транзакцию всего помещения. Точный угол проблемного вида без RVT и запуска в Revit 2024 не установлен.

Обоснованная гипотеза первичного сбоя — REVIT-134773: одиночный большой поворот ElevationMarker иногда получает дополнительные 180°. Autodesk опубликовал обход поворотами по 30°; конкретный порог зависит от ситуации, поэтому проверка только ровно 180° недостаточна. Источники: [обсуждение Autodesk](https://forums.autodesk.com/t5/revit-api-forum/elevationmarker-does-not-rotate-180-deg/td-p/8010880), [публикация Autodesk Developer Technical Services](https://jeremytammik.github.io/tbc/a/1672_cmdwallprofile_2019.html#5).

1. Поворачивать маркер кратчайшим знаковым углом, шагами не более 30°, после каждого обновлять документ и считывать фактическое направление. Ограничить число шагов и сохранить итоговую проверку; ошибка сообщает остаточное отклонение.
2. Создание и именование каждого вида — SubTransaction. Перехватываемая ошибка отменяет этот вид и маркер; остальные продолжаются. Номер развёртки соответствует исходной границе. Общая Transaction помещения и группа Undo сохраняются, окончательная статистика учитывает результат внешнего Commit. Ошибки регенерации документа не подавлять.
3. Регрессионные проверки: модель известного лишнего поворота на 180°, обычные и повёрнутые исходные оси, остановка при неподвижном маркере; средняя неудачная граница, все неудачные и фатальная ошибка. Модель API в тесте не заменяет проверку исходной комнаты в Revit.
4. Review, сборки обоих проектов Revit 2019–2026, затем merge master и push. DLL — собственные bin проектов, диагностика — artifacts/build.

Проверено 8 сентября: 84/84 регрессионных тестов, включая совместный сценарий неподвижного второго фасада с успешными первым и третьим. До исправления 33 проверки поворота и две проверки пропуска воспроизводили ошибки прежних алгоритмов на тестовых моделях. Все 16 сборок проходят без предупреждений и ошибок. Независимый review не выявил дефектов. Реальное помещение 6289801 и работа SubTransaction/Undo внутри Revit 2024 остаются ручными сценариями приёмки.
