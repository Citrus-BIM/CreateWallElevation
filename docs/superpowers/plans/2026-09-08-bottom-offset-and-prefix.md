# Нижняя граница и префикс имён

Запрос: разрешить отрицательное смещение снизу для показа пола и ввод префикса создаваемых видов. Работа в отдельной ветке исходной папки; затем master, origin и сборки обоих проектов Revit 2019–2026 в собственные bin.

- Нижняя граница = исходный низ + смещение. −100 мм расширяет вид вниз; +100 мм поднимает низ. Проверять конечность чисел и положительную итоговую высоту. Сохранённый положительный отступ прежней версии переводить в отрицательное смещение, сохраняя положение рамки.
- Поле «Префикс имени вида» сохраняется в XML. Пустое значение оставляет прежние имена; непустое заменяет автоматическую часть, сохраняя номер помещения, номер развёртки и ID. Запрещённые символы сообщать до выбора объектов.
- Общая логика обоих вариантов; темы окон сохранить. Добавить регрессионные проверки ввода, рамки, имён и совместимости XML.
- Проверить обе границы платформ сборкой всех восьми конфигураций, выполнить независимый review. Слияние и push после проверок. Логи и manifest — artifacts/build, поставка — только штатные bin.

Проверено 8 сентября: 40/40 регрессионных тестов; до исправления три новых теста нижней границы воспроизводили ошибку. Все 16 сборок проходят без предупреждений и ошибок. Оба XAML проверены через WPF Measure/Arrange и рендер с темами: поле не обрезается при высоте окна 620. Независимый review не выявил дефектов. Запуск команды внутри Revit не выполнялся; ручные сценарии перечислены в docs/REVIT-ACCEPTANCE.md.
