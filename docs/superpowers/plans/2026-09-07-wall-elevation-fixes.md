# Wall elevation fixes implementation plan

**Goal:** исправить согласованный аудит, объединить в master, отправить origin/master и собрать обе версии для Revit 2019–2026 в текущей папке проекта.

**Architecture:** общий расчёт геометрии и создание видов для обычной и Spectrum-версии; отдельные существующие точки входа и оформление окон. Чистые расчёты проверяются без Revit; операции с документом остаются на потоке Revit в транзакциях.

**Tech stack:** C#, .NET Framework 4.8 / .NET 8, Revit API 2019–2026, WPF. Требования и порядок исправлений одобрены пользователем в продолжении AUDIT-2026-09-07.md; дополнительная остановка на согласование не требуется.

- [x] Сохранить существующие изменения отдельным коммитом в ветке codex/fix-wall-elevation-audit.
- [x] Добавить регрессионные проверки направлений четырёх стен, локальных нормалей вогнутой комнаты, единственного смещения дуг, слияния коротких частей до фильтрации, разрывов контура, нижней отметки, параметров, безопасных XML-настроек и размещения прямоугольников на занятом листе.
- [x] В Shared/Geometry2D.cs реализовать вычисления без Revit. Для границ использовать истинные параметры Curve.Evaluate и локальную проверку принадлежности исходному контуру в плане с отверстиями; не выводить нормаль из единственного центра комнаты.
- [x] В Shared/WallElevationBuilder.cs унифицировать создание разрезов и фасадов: observerDirection внутрь комнаты/к выбранной стороне, один отступ от поверхности, BasisZ разреза против observerDirection, ViewDirection фасада по observerDirection.
