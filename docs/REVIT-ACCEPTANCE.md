# Приёмка исправлений в Revit 2019–2026

Использовать копию тестового проекта. Математические проверки и компиляция не заменяют запуск команды в Revit. В ходе разработки 7–8 сентября 2026 автоматический запуск внутри Revit не выполнялся.

## Обязательные сценарии

1. Прямоугольное помещение. «По помещению → Фасад», отступ 300 мм, глубина 350 мм, без шаблона. Все четыре вида смотрят на свои стены; маркеры внутри. Повторить на повёрнутом плане.
2. То же помещение через разрезы: проверить направление, рамку, верх/низ, глубину и отсутствие зеркальной ориентации содержимого.
3. По прямой стене: выбрать обе стороны, стену после Flip, смещение снизу −100 мм. Низ рамки должен быть ниже низа стены на 100 мм. Повторить по помещению для разрезов и фасадов. При +100 мм низ поднимается, при 0 совпадает с исходным; слишком большое положительное смещение даёт понятную причину пропуска объекта.
4. Дуга 90°/270°: фасады и разрезы, оба обхода и обе стороны стены, 10–20 сегментов, достаточная глубина. Отступ соответствует значению, концы сегментов находятся на одной поверхности. Недостаточные глубина или число сегментов дают понятную причину пропуска.
5. U-образная комната и комната с внутренним островом: локальные направления у ниш и острова обращены от наблюдателя к границе.
6. Стена 2400 мм из четырёх коллинеарных частей по 600 мм, минимальная длина 1000 мм: развёртка всей стены сохраняется. Короткая ниша не превращается в соединяющую прямую.
7. Этаж выше нуля, ненулевой нижний отступ комнаты и общие координаты: рамка совпадает с ограничениями комнаты. Комната под наклонной крышей не пропускается только из-за фиксированной высоты проверки стороны.
8. Шаблон с разрешённой геометрией: его стиль и масштаб сохраняются, рамка/глубина соответствуют вводу. Шаблон с заблокированной несовместимой глубиной: объект пропускается, причина показана, исходный шаблон не меняется. Отключение галки снимает также default template типа вида.
9. Несколько помещений, одно некорректное: успешные результаты остаются, проблемное отражено в отчёте. Общая операция отменяется одной командой Undo. Отмена выбора до построения ничего не создаёт.
10. Лист уже содержит виды, подписи и аннотации: новые виды их не перекрывают. При заполненном листе созданные виды остаются в диспетчере без видового экрана. Повторный запуск не накладывает виды на прежние.
11. Пустые/NaN/бесконечные числа, отрицательные значения полей кроме «Смещение снизу», дробное или нулевое число сегментов: окно остаётся открытым с причиной. Десятичная запятая и точка принимаются. Нижнее смещение принимает −100,5, -100.5, +100 и 0. Значение минимальной длины сохраняется после запуска «По стене».
12. Повреждённый пользовательский XML: окно открывается с исходными значениями. Старый XML рядом с DLL читается при отсутствии нового. Недоступность записи не мешает запуску с выбранными параметрами.
13. Без сохранённых настроек смещение снизу равно 0. Прежний XML с положительным нижним отступом 100 показывает −100, сохраняя положение рамки. После сохранения и повторного открытия знак не меняется; новое +100 также сохраняется без инверсии.
14. Пустой префикс оставляет прежние имена. Префикс «АР» даёт АР_101_1_<ID> для помещения 101 и АР_1_<ID> для стены в обоих типах видов. Несколько помещений, повторное построение и занятые похожие имена не приводят к потере видов. Префикс сохраняется между запусками. Двоеточие/обратная косая черта в префиксе дают сообщение в форме до выбора объектов.

Для каждого выполненного сценария записать год Revit, вариант плагина, SHA из artifacts/build/build-manifest.json и фактический результат. При дефекте приложить минимальный RVT и значения параметров.
